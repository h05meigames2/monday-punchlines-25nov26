Entry for the [Monday Morning Punchlines](https://make.fun/competitions/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun — one original joke about Monday mornings, no longer than 200 characters.

## The joke

> My alarm called in sick this Monday, so I stayed in bed out of solidarity — turns out even my clock is on team weekend.

119 characters. The alarm, the bed, and the clock all conspire against Monday — and the punchline flips the blame from the sleeper to the clock itself, which is secretly on team weekend.

## How it works

`main.py` is a small deterministic Python script: no network, no randomness, no dependencies. It writes the single joke line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Run

```bash
python3 main.py
# or with a custom output directory:
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
